# Тестирование — Электротехника

Интерактивный сайт с тестом по электротехнике.

## Возможности

- 240 вопросов;
- 12 вариантов по 20 вопросов;
- режим случайных 20 вопросов;
- режим всех 240 вопросов;
- автоматическая проверка;
- подсветка правильных и неправильных ответов;
- прогресс прохождения;
- полностью автономный `index.html`, без внешних библиотек.

## GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите `index.html` в корень репозитория.
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**.
5. Branch: `main`, Folder: `/ (root)`.
6. Нажмите **Save**.

После публикации GitHub Pages покажет адрес сайта.
